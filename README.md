# 🪨 PetRock - Adote uma Pedra como Pet!

Bem-vindo ao **PetRock**! 

Um site divertido e criativo que mostra por que adotar uma pedra como animal de estimação pode ser a melhor (e mais sólida) decisão da sua vida.

Este projeto foi desenvolvido com o objetivo de **estudar e praticar HTML e CSS**, combinando aprendizado técnico com uma proposta leve, bem-humorada e visualmente agradável.

---

## 🌟 Funcionalidades do Site

- ✅ Página inicial com título e introdução descontraída
- ✅ Seção com diferentes tipos de PetRocks
- ✅ Dicas sobre como cuidar da sua pedra de estimação
- ✅ Argumentos convincentes (e divertidos) sobre por que adotar uma pedra é uma excelente ideia
- ✅ Design simples, limpo e responsivo usando apenas HTML e CSS

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** para estrutura do conteúdo
- **CSS3** para estilização e layout visual

> Nenhum JavaScript foi utilizado neste projeto. O foco foi exclusivamente o estudo de HTML e CSS.

---

## 📁 Estrutura dos Arquivos

📦Pet-Rock/
┣ 📜 `index.html`       → Estrutura principal do site
┣ 📜 `diferentes.html`  → Diferentes tipos do seu PetRock
┣ 📜 `como.html`        → Como cuidar do seu PetRock
┣ 📜 `style.css`        → Estilos aplicados ao layout e conteúdo
┣ 📷 `assets/`          → Imagens das PetRocks
┣ 📷 stone_icon.png (favicon)

---

## 📱 Compatibilidade com celular e tablet

O layout foi feito usando `flexbox` e media queries para funcionar bem em celulares e tablets.  
Os botões se ajustam, os textos continuam legíveis, e tudo se adapta ao tamanho da tela.
